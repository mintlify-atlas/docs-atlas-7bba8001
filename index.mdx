## Why Monochromium?

Most note-taking tools require switching context — opening a browser tab, an Electron app, or a mobile device. Monochromium stays in the terminal where developer workflows live.

<CardGroup cols={2}>
  <Card title="Fully local" icon="database">

  </Card>
  <Card title="Tiny binary" icon="feather">

  <Card title="Four note types" icon="tags">

## Quick example

```bash
# Add an idea
mono add "Refactor the auth module" --type idea

# Log a check-in
mono checkin "Feeling focused, deep-work session going well"

# List today's notes
mono list --today

# Search across all notes
mono search "auth"
```

<Steps>
  <Step title="Install via Cargo">
    ```bash
    cargo install monochromium
    ```
  </Step>
  <Step title="Verify the install">
    ```bash
    mono --version
    ```
  </Step>
  <Step title="Enable shell reminders (optional)">
    ```bash
    mono init
    ```
    This appends a `mono reminder` hook to your `~/.zshrc` so you get nudged if you haven't checked in for a while.
  </Step>
  <Step title="Capture your first note">
    ```bash
    mono add "Hello from Monochromium!"
    ```
  </Step>
</Steps>
