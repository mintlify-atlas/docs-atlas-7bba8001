`mono list` retrieves and displays notes from your local database in reverse-chronological order. By default it returns the 15 most recent notes, showing each note's title and ID on a single line. Use filters to narrow the results by note type, date range, or today only, and add `--view` to expand each entry to include its full content.

## Synopsis

```bash
mono list [--limit <N>] [--type <TYPE>] [--today] [--since <YYYY-MM-DD>] [--view] [--copy]
```

## Arguments

`mono list` takes no positional arguments. All filtering is done through flags.

## Flags / Options

<ParamField path="--limit, -l" type="u16">
  Maximum number of notes to return. Defaults to `15`. Accepts any positive integer up to 65535.
</ParamField>

<ParamField path="--type, -t" type="idea | todo | check-in | other">
  Restrict the results to notes of a specific category. When omitted, notes of all types are returned. Valid values are `idea`, `todo`, `check-in`, and `other`.
</ParamField>

<ParamField path="--today" type="boolean">
  Only show notes created today. Useful for a quick end-of-day review of everything you captured. Cannot be combined with `--since` for overlapping ranges — use one or the other.
</ParamField>

<ParamField path="--since, -s" type="YYYY-MM-DD">
  Show all notes created on or after the given date. Useful for weekly or sprint-scoped reviews. Accepts ISO 8601 date format (`2025-01-01`).
</ParamField>

<ParamField path="--view, -v" type="boolean">
  Expand the output to include the full content of each note beneath its title line. Without this flag only the title and ID are shown.
</ParamField>

<ParamField path="--copy, -c" type="boolean">
  Global flag. Copy the full formatted output to the clipboard after printing.
</ParamField>

## Examples

```bash
# Show the 15 most recent notes (default)
mono list

# Show the 30 most recent notes
mono list --limit 30

# Show only idea notes
mono list --type idea

# Show only todo notes, expanded with content
mono list --type todo --view

# Show all notes from today
mono list --today

# Show all notes since the start of the week
mono list --since 2025-01-13

# Show the 5 most recent check-ins with content expanded
mono list --type check-in --limit 5 --view

# Show notes from this month and copy the output to clipboard
mono list --since 2025-01-01 --copy
```

## Output

**Without `--view`** (default): one line per note showing the title and ID.

```
Rewrite the onboarding flow • ID: 42
Email Alex about the Q3 retro • ID: 41
What if we stored tags as • ID: 40
Ship the beta by end of • ID: 39
```

**With `--view`**: each note is expanded with its full content, timestamp, and ID.

```
Rewrite the onboarding flow • ID: 42 • Jan 15, 2025 at 9:30 AM
 Rewrite the onboarding flow to be less intimidating

Email Alex about the Q3 retro • ID: 41 • Jan 15, 2025 at 8:45 AM
 Email Alex about the Q3 retro before EOD Friday
```

Each entry follows the format: `TITLE • ID: N • Month DD, YYYY at H:MM AM/PM` with the content indented on the following line.

If no notes match the applied filters, the output is empty.
