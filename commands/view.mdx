---
title: "mono view — display note content and copy to clipboard"
sidebarTitle: "view"
description: "mono view prints the full content of a note by its integer ID and always copies the output to your clipboard automatically — no flag needed."
---

`mono view` fetches a single note from the local SQLite database by its integer ID and prints its title, ID, timestamp, and full body text to the terminal. It is the fastest way to recall the exact content of any note without scrolling through a full listing. Output is **always** copied to your clipboard automatically — no extra flag required.

## Synopsis

```bash
mono view <NOTE_ID> [OPTIONS]
```

## Arguments

<ParamField path="note_id" type="u32" required>
  The integer ID of the note you want to display. IDs are assigned sequentially when notes are created and can be found with `mono list`.
</ParamField>

## Flags / Options

<ParamField path="--no-format" type="boolean">
  Strips Markdown formatting from the note's output before printing. Short: `-n`.

  > **Note:** This flag is currently unimplemented. Passing it has no effect on output.
</ParamField>

## Examples

View note with ID 1:

```bash
mono view 1
```

View note with ID 42:

```bash
mono view 42
```

View a note and immediately pipe the output into `less` for scrollable reading (clipboard copy still occurs):

```bash
mono view 15 | less
```

Look up a note ID first, then view it:

```bash
mono list
mono view 7
```

## Output

Each call to `mono view` prints a single formatted note block to stdout:

```bash
Meeting Notes • ID: 7 • Jan 05, 2025 at 2:30 PM
 Discussed Q1 roadmap. Action items: update spec doc, schedule follow-up for Jan 12.
```

The line format is:

```bash
TITLE • ID: N • Mon DD, YYYY at H:MM AM/PM
 CONTENT
```

The note's full body text appears on the second line, indented by one space. In addition to printing to the terminal, the exact same string is silently placed on your clipboard so you can paste it anywhere without a separate copy step.
