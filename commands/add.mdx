title: "mono add — create and save a new note from the CLI"

description: "mono add creates a note with optional type, custom timestamp, and clipboard paste support. Key flags: --type, --time, --date, --paste, --copy."
---

`mono add` is the primary way to capture notes into Monochromium's local SQLite database. Pass the note body directly as a positional argument, pull it from your clipboard with `--paste`, or omit it entirely to see a prompt reminding you to supply text. Every note gets a title (derived from the first five words of its content), a unique numeric ID, and a timestamp — all configurable at creation time.

## Synopsis

```bash
mono add [TEXT] [--type <TYPE>] [--time <HH:MM>] [--date <YYYY-MM-DD>] [--paste] [--copy]
```

## Arguments

<ParamField path="TEXT" type="string">
  The body of the note. Optional — if omitted and `--paste` is not set, the command returns a prompt message asking you to supply content. Passed as a bare positional argument (no flag needed).
</ParamField>

## Flags / Options

<ParamField path="--type, -t" type="idea | todo | check-in | other">
  The category to assign to the note. Defaults to `other` when not specified. Use `todo` for actionable items, `idea` for exploratory thoughts, `check-in` for wellbeing logs, and `other` for everything else.
</ParamField>

<ParamField path="--time" type="HH:MM | HH:MM:SS">
  Override the time component of the note's timestamp. Accepts 24-hour format (`14:30`) or with seconds (`14:30:00`). Defaults to the current local time when omitted.
</ParamField>

<ParamField path="--date" type="YYYY-MM-DD">
  Override the date component of the note's timestamp. Useful for backdating notes. Defaults to the current local date when omitted.
</ParamField>

<ParamField path="--paste, -p" type="boolean">
  Read the note body from the system clipboard instead of from the `TEXT` argument. Handy for capturing longer content you've already copied. Takes precedence over a supplied `TEXT` argument.
</ParamField>

<ParamField path="--copy, -c" type="boolean">
  Global flag. After the note is saved, copy the formatted output string to the clipboard so you can paste it elsewhere.
</ParamField>

## Examples

```bash
# Create a basic note with default type and timestamp
mono add "Rewrite the onboarding flow to be less intimidating"

# Create a todo note
mono add "Email Alex about the Q3 retro" --type todo

# Create an idea note backdated to yesterday
mono add "What if we stored tags as a bitfield?" --type idea --date 2025-01-14

# Log a note at a specific time earlier today
mono add "Sync with design team — decisions logged in Figma" --time 09:45

# Fully custom timestamp
mono add "Late night thought about caching strategy" --type idea --date 2025-01-13 --time 23:15

# Paste clipboard content as the note body
mono add --paste --type other

# Create a note and copy the formatted output to clipboard
mono add "Ship the beta by end of sprint" --type todo --copy
```

## Output

On success, `mono add` prints a single formatted line followed by the note content:

```text
Rewrite the onboarding flow • ID: 42 • Jan 15, 2025 at 9:30 AM
 Rewrite the onboarding flow to be less intimidating
```

The format is: `TITLE • ID: N • Month DD, YYYY at H:MM AM/PM` followed by a newline and a space-indented copy of the full note content.

The title is automatically generated from the first five words of the note body.

If no text is provided and `--paste` is not set, the command returns:

```text
Please provide a message when making your note!
```
