This guide takes you from a fresh machine to a fully working note-taking workflow in under five minutes. You'll install `mono`, capture your first notes across multiple types, search your history, and wire up the optional shell reminder system — all without leaving the terminal.

<Steps>
  <Step title="Install Monochromium">
    Install the `mono` binary from Cargo. This is the recommended install path for all platforms:

    ```bash
    cargo install monochromium
    ```

    Cargo will compile and place the `mono` binary in `~/.cargo/bin`. Make sure that directory is on your `PATH` (it is by default if you installed Rust via `rustup`).
  </Step>

  <Step title="Verify the install">
    Confirm the binary is available and check your installed version:

    ```bash
    mono --version
    ```

    Expected output:

    ```
    mono 0.3.0
    ```
  </Step>

  <Step title="Add your first note">
    Create a plain note with `mono add`. The note is saved immediately to your local SQLite database:

    ```bash
    mono add "My first note"
    ```

    Expected output:

    ```
    My first note • ID: 1 • Jan 01, 2025 at 9:00 AM
     My first note
    ```

    The first line is the note header (title, ID, and timestamp). The indented second line is the note content.
  </Step>

  <Step title="Add a todo">
    Use the `--type` flag to categorize a note as a `todo`. Todos are tracked separately and can be listed with `mono todos`:

    ```bash
    mono add "Ship the feature" --type todo
    ```

    Expected output:

    ```
    Ship the feature • ID: 2 • Jan 01, 2025 at 9:01 AM
     Ship the feature
    ```
  </Step>

  <Step title="Log a check-in">
    The `mono checkin` command is a shorthand for creating a `check-in` type note — ideal for daily mood logs or stand-up notes. No `--type` flag needed:

    ```bash
    mono checkin "Feeling productive today"
    ```

    Expected output:

    ```
    Feeling productive today • ID: 3 • Jan 01, 2025 at 9:02 AM
     Feeling productive today
    ```
  </Step>

  <Step title="List today's notes">
    Review everything you've captured today with the `--today` flag:

    ```bash
    mono list --today
    ```

    Expected output:

    ```
    My first note • ID: 1 • Jan 01, 2025 at 9:00 AM
    Ship the feature • ID: 2 • Jan 01, 2025 at 9:01 AM
    Feeling productive today • ID: 3 • Jan 01, 2025 at 9:02 AM
    ```

    You can also filter by type (`--type todo`), cap the results (`--limit 10`), or include note content inline (`--view`).
  </Step>

  <Step title="Search your notes">
    Full-text search across all note content with `mono search`:

    ```bash
    mono search "feature"
    ```

    Expected output:

    ```
    Ship the feature • ID: 2 • Jan 01, 2025 at 9:01 AM
    ```

    Narrow results further with `--type`, `--limit`, or `--date` flags.
  </Step>

  <Step title="View a note's full content">
    Retrieve the full content of any note by its ID. The output is also automatically copied to your clipboard:

    ```bash
    mono view 1
    ```

    Expected output:

    ```
    My first note • ID: 1 • Jan 01, 2025 at 9:00 AM
     My first note
    ```
  </Step>

  <Step title="Enable shell reminders">
    Opt into the reminder system by running `mono init`. This appends a small hook to your `.zshrc` that calls `mono reminder` each time you open a new shell, surfacing a note from your history:

    ```bash
    mono init
    ```

    Open a new terminal session after running this command for the reminder hook to take effect.
  </Step>
</Steps>
